# Checkliste vor der Abgabe (jede Frage mit Ja beantworten können)

**Hierarchie**
- [ ] Auf jedem Bildschirm ist in 1 Sekunde klar, was die Hauptaktion ist.
- [ ] Genau ein Element leuchtet stark; alles andere ist ruhig.
- [ ] Nebenfunktionen sind visuell leiser als Hauptfunktionen.

**Konsistenz**
- [ ] Nur Farben aus `tokens.md`, max. zwei Neon-Farben prominent pro Bildschirm.
- [ ] Alle Oberflächen-Icons sind Linien-Icons aus `Icon.tsx` – keine Emojis in Navigation/Kacheln/Tabs.
- [ ] Abstände nur aus dem 4-px-Raster; gleiche Elemente haben gleiche Abstände.
- [ ] Display-Schrift wird im Screenshot wirklich angezeigt (nicht Systemschrift).

**Lesbarkeit**
- [ ] Nebentext ≥ 13 px und gut lesbar auf dunklem Grund.
- [ ] Keine Texte über unruhigen Mustern ohne Abdunklung.
- [ ] Am Handy (390 px) nichts abgeschnitten, kein seitliches Scrollen.

**Inhalt & Grenzen**
- [ ] Keine Gesichter, keine Personen, keine Personen-Emojis.
- [ ] Struktur, Navigation, Texte, Funktionen unverändert (wenn nur Design gefragt war).
- [ ] Event-Look nur im Event-Zeitraum.

**Gegen den KI-Standardlook**
- [ ] Würde man das Spiel ohne Logo wiedererkennen? (eigene Formen: abgeschrägte Karten-Ecken, Raster, Neon-Kante)
- [ ] Nicht überall derselbe Verlauf/dieselbe Kachel – es gibt Größen- und Gewichtsunterschiede.
- [ ] Etwas weglassen: Welches Deko-Element kann weg, ohne dass es fehlt? Eins streichen.
